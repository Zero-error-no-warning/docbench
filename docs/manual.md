# 操作ガイド

## 空の新規書類を作る

編集者画面の左サイドバー上部「＋ 新規書類」を押し、書類名・説明・最初の出力形式を指定して「新規作成」を押します。入力項目・入力値・独自の型・出力デザインを引き継がない、独立した書類になります。標準型は新しい書類でも使用できます。

現在の内容は作成前に自動バックアップします。直後ならUndoで元の書類へ戻せます。「保存・読込 → 自動バックアップから復元」からも復元できます。作成画面の「現在の全体を保存」で、先にファイルへ残すこともできます。入力者画面では新規書類ボタンを表示しません。

## 型を定義する

左サイドバーの「型を定義」から、繰り返し使う入力形式を管理します。標準で「和暦年度」「和暦年」があります。標準型をそのまま要件定義で選ぶこともできます。

1. 「＋ 型を追加」で独自の型を作成します。標準型などを元にする場合は「型を複製」を使います。
2. 型の名前・キー・説明を設定し、左の構造から編集する項目を選びます。Objectの子項目、Array・Table、規則、単位・表示名も設定できます。右の入力プレビューは書類データと独立しています。
3. 「要件を定義」で項目を追加し、データ型の「登録した型」から選ぶとすぐに使えます。書類固有の項目名・必須・条件は、書類側で設定します。

   複合型の子項目を選び、「表示条件」から「ノードで編集」を開くと、その複合型内の項目で比較・AND・OR・NOTを組み合わせられます。単純な一致条件は同じ設定欄で直接指定できます。ノードの変更も「型定義に反映」でまとめて確定します。たとえば「CはAが『はい』のときだけ表示」と設定すると、登録型を使う各項目や明細行が、それぞれのAでCの表示を判定します。書類側にも表示条件を設定した場合は、両方を満たすときだけ表示します。
4. 使用中の型は「型を開く」から編集できます。変更は同じ書式内の全使用箇所に反映され、型と使用箇所をまとめてUndo/Redoできます。型だけの版番号・公開・更新確認はありません。

既存の項目は「この項目を型として登録」で再利用可能な型にできます。個別編集へ戻すには「通常の項目に展開」を押します。使用中の型は削除できません。構造を削除・変更すると入力値も変わるため、必要に応じて「履歴・派生」で書式全体の状態を記録してください。

型定義はDefinitionに保存され、入力項目・条件・出力デザインとともに書式全体の履歴で管理します。全てを一緒に保存するには「全体」を選びます。別の書式へ型をコピーする場合は「型を定義」の「型定義を保存」でTypeLibraryのJSONを出力し、「型定義を読込」でJSON/gzipを追加できます。同じIDで異なる定義があっても既存型を上書きせず、別の型として追加します。

旧ファイルに異なる版や下書きがある場合は、内容を保った複数のローカル型に移行します。従来の入力値と使用箇所の構造は保持します。

## 部署などの階層選択を作る

1. 「型を定義」で型を追加し、データ型に「TreeEnum」を選びます。要件定義の項目へ直接TreeEnumを設定することもできます。
2. 「階層選択の設定」で選択肢をクリックし、名前を入力します。「＋ 最上位」「＋ 子」で追加し、「親の選択肢」で移動、矢印で並び替えできます。異なる親の下なら同じ名前を使えます。
   多くの選択肢をまとめて編集する場合は「テキストで編集」を選びます。1行に1選択肢、行頭のTabが1つ増えるごとに1階層深くなります。Tab / Shift+Tabは選択行の字下げ、Ctrl+Z / Ctrl+Shift+Zはテキスト内のUndo / Redoです。Escで編集欄から移動できます。行番号付きのエラーと追加・削除・名前変更・移動の件数を確認し、「テキストを適用」で書式に反映します。適用後の変更は書式全体のUndoで戻せます。

   通常の1行ずつの編集では既存IDを保持します。外部ツールで名前変更・移動を含めて全体を書き換える場合は「IDを表示（外部編集用）」を有効にし、IDを残してください。IDを対応付けられない貼り替えは追加・削除として表示し、無関係なIDを割り当てません。保存ファイルにはテキストではなく通常の選択肢ツリーを格納します。

3. 「末端のみ／途中階層も選択可」、入力方法「階層ごとのプルダウン／検索付きツリー」、初期値、出力する名前と区切りを設定します。
4. 要件定義で登録した型を選ぶと、階層に沿って入力できます。親を変更すると子の選択は解除されます。保存するのは選択肢IDの経路で、出力には名前を使います。
5. 「条件を設計 → 階層選択の項目 → ＋ 階層選択の判定」から、一致する部署、またはその部署以下の条件を作れます。結果をAND/OR/NOTや入力の表示・必須・書類生成へ接続できます。

名前を変更しても入力済みの選択は維持します。部署を移動すると入力値と条件の経路も追従します。選択肢を削除した場合は入力値を保持し、検証で選び直しを表示します。型と使用箇所の変更は書式全体のUndo・履歴で戻せます。

## 定義者

URL末尾に`#editor`を付けるか、入力者画面の「編集者画面へ」を押して開く。編集中のデータを保持したまま、「入力者画面へ」で入力画面に切り替えられる。

1. 「要件を定義」を開く。左側の「項目追加」から項目を追加する。
2. 項目を選択し、表示名・項目キー・データ型を設定する。キーは英字から始まる英数字とアンダースコア。
3. セクション・グループ・説明を指定する。必須・文字数・数値範囲・選択肢は型に応じて表示される。
4. 条件付き必須は、参照項目と比較する値を指定する。文字列はそのまま、真偽値は`true`/`false`、数値は数字を入力する。
5. Objectは「子項目を追加」。TableとObject要素のArrayは、左側の列項目を選んで編集する。単純型のArrayは要素型を選択する。
6. 配列・表の追加/削除/複製/並び替えの許可、最小/最大要素数、初期行数、行名、業務キー、重複禁止列、整列列を設定する。初期行数の変更は新しいデータの初期値に適用され、既存の入力行を書き換えない。
7. ドラッグまたは項目設定の上/下ボタンで、同じ階層の項目を並び替える。
8. 「出力を設計」で最初に形式を選ぶ。Wordは用紙・余白と段落書式、Excelは開始セル・結合・列幅・数値書式、PowerPointはスライド番号・位置・サイズ、HTML/PDFはテンプレート・CSSを設定する。形式ごとに入力項目・表・見出し・文章・改ページを追加する。出力ルールを開き、必要に応じて条件・別添化の文字数・表の行数を設定する。
9. 右側で現在の入力データを使った結果を確認する。Officeは「出力して確認」で実ファイルも確認する。形式を切り替えても各デザインの設定は保持される。任意のDocument Dataを読み込むとサンプルとして使用できる。
10. 「保存・読込」から要件定義と出力定義をそれぞれ保存する。全体を保存すると履歴と派生も保持できる。

## 画面上での配置・書式変更

「出力を設計」で形式を先に選び、右側の編集領域で配置と書式を設定する。Wordでは「詳細設定」、Excelでは「ページ・要素の設定」から用紙・全体書式と要素一覧を開く。通常は文書・セルの編集領域を広く表示する。文字サイズ・フォント・太字・斜体・下線・取消線・色・背景・文字揃えは書式ツールバーにある。Wordは上部2段のコンパクトなバーと、右側の共通作業パネルを使う。その他のPC画面では初期状態で右半分を編集・プレビューに使い、保存・履歴の上部バーを左側の上に配置する。ペインの境界をドラッグすると横幅を調整でき、上部バーも境界に追従する。設定・書式はその下で操作する。背景は「背景なし」、罫線は「罫線」メニューで全周・下罫線・なしを設定する。項目ブロックは「対象」で全体・項目名・入力値を選び、別々に設定できる。選択中の要素だけ左側に詳細を表示する。

- **Word**：文章・表は最初からTiptapで編集できる。クリックしてカーソルを置き、そのまま入力する。左端に表示されるつまみをドラッグして段落・表を移動する。文字の一部を選択して書式を変更できる。「表」の作業パネルで任意の行数・列数を指定して「表を挿入」を押す。表の中を選ぶと「表」タブを表示する。行・列の追加/削除、結合/分割、見出し行・列はこの欄で操作する。Shift+クリックで複数セルを選択する。セル背景・罫線・余白・縦揃えは「表」タブで設定する。罫線の対象は初期状態で「選択セル」。色・太さ・種類を選んで「上辺」「下辺」「左辺」「右辺」を押すと、その辺だけを変更する。「指定した辺を消す」をオンにして辺を押すと、その辺だけを消す。「まとめて指定」で外枠・内側・すべて・なしを選べる。表全体へ適用する場合は対象を「表全体」に切り替える。罫線なしのセルにも編集用の点線を表示するが、点線は成果物に出さない。列境界をドラッグして幅を変える。セル内にさらに表を挿入できる。「罫線なし」は通常のセル設定であり、列数や用途の専用モードではない。表内を含むカーソル位置に、選択した項目の「入力値」または「項目名」を差し込める。設計中は参照チップ、成果物は実際の入力値になる。入力データは出力定義へ保存しない。
- **Excel**：Jspreadsheetのセルをドラッグして範囲を選び、書式や結合/解除を設定する。書式変更では選択とグリッドを保持する。アドレス欄へB3:D4のように入力して範囲へ移動できる。「セル内容」から選択セルの固定文字を編集し、「表示形式」で数値表示を指定できる。空白セルや固定文章はダブルクリックして入力できる。入力項目に紐づくセルは読み取り専用で、値は入力フォームで変更する。列幅・行高は見出し境界をドラッグする。項目を挿入するか、既存要素を選んで「選択範囲へ配置」する。表は開始セルから入力行を展開する。値があるセルを潰す結合や重なる配置はエラーになる。`=`で始まる固定文字も文字列として扱い、計算式を実行しない。グリッドの編集範囲は500行・100列まで。
- **PPTX**：Konvaのスライド上で文字・項目・表・画像・四角・楕円・線を配置する。ドラッグで移動、ハンドルでサイズ変更と回転、ツールバーで角度を数値指定する。表は回転できない。初期状態は0.1cmに合わせる。Altを押すか設定を解除すると細かく動かせる。矢印キーは0.1cm、Shift+矢印は1cm。「前面へ」「背面へ」は重なり順を変える。固定文章はダブルクリックで編集する。出力は編集可能なOfficeオブジェクトとなる。
- **HTML / PDF**：段落・項目・表をドラッグして並び替える。HTMLテンプレートとCSSを変更し、独自classを設定できる。GUIで明示的に設定した書式はインラインで優先される。

Ctrl+Zで元に戻す、Ctrl+Shift+Zでやり直す。文章入力中は文字編集のUndo、編集領域の外では全体のUndoになる。選択した要素はCtrl+Dで複製、Deleteで削除できる。表示倍率や編集用ガイドは成果物に入らない。Wordのページ送り・折返し、PowerPointの文字縮小などはOfficeと異なることがあるため、「出力して確認」で実ファイルも確認する。

## 定義の下書きと実際の入力

型定義・要件定義・条件定義では、その画面全体を下書きとして編集します。下端の「型定義に反映」「要件に反映」「条件に反映」でまとめて確定し、「キャンセル」でその画面の未適用分を破棄します。下書きは画面移動や再読込後も保持します。反映前の変更は入力画面、出力、正式なJSONへ入りません。反映前に項目数と入力値への影響を表示し、競合する変更は確定を止めます。型定義をJSONへ保存する場合も先に反映してください。

要件のフォームプレビュー、条件の判定用入力、型のテスト入力は、実際の入力値と独立しています。「入力・書類作成」では確定済みの定義に基づいて実際の値を直接編集し、自動保存します。項目検索・区分移動・エラー一覧から入力欄へ移動できます。

## Wordの編集と仕上がり確認

### 既存のWord様式を取り込む

「出力を設計」の「Word様式を取り込む」、または「保存・読込」の「Word様式（.docx）を取り込む」からファイルを選びます。20MBまでの通常の.docxが対象です。ファイルはこのブラウザー内で変換し、外部へ送信しません。

段落数・表の数、本文の抜粋と注意点を確認し、書類名を付けて「出力書類として追加」を押します。既存の出力書類・入力項目・入力値は保持し、新しいWord出力書類へ追加します。元のDOCXは変更しません。追加前のバックアップとUndo／Redo、通常の保存・再読込に対応します。「取り込み結果」から注意点を再確認できます。

文章、見出し、基本的な文字／段落書式、使用中の段落スタイル、番号、表の横・縦結合、列幅比率、各辺の罫線（色・太さ・実線／破線／点線／二重線）、A4／Letter・向き・余白を取り込みます。表スタイルの継承、外枠と内側の区別、セルの直接指定、先頭行などの条件付き罫線を各セルへ反映します。ヘッダー／フッターは共通の文字列へまとめます。文章を選択して入力項目へ置き換え、差し込み用の様式として利用できます。

画像・図形・テキストボックス・脚注などは位置の目印になります。リンク先、複雑な表スタイル、固定行高、テーマ書式、途中のセクション設定なども再現できない場合があります。注意点を確認してから追加し、出力したDOCXをWordでも確認してください。.doc・.docmはWordで通常の.docxへ保存し直してください。

### 編集と確認表示

出力設計のWordでは、上部の「書式」「差し込み」「くり返し・条件」「表」「ページ」で右側の作業パネルを切り替えます。検索や候補の選択だけでは本文は変わりません。「差し込む」「設定」「適用」のボタンで確定します。閉じる／Escapeは作業中の設定を保持し、キャンセルは破棄します。「ファイル」には保存・読込・履歴・書類の追加・複製・削除・出力形式の選択・Word様式の取り込みがあります。本文の選択を保持したままパネルを操作でき、上部84px・下部28pxを除いた高さを編集領域に使います。幅が足りない場合は同じパネルを主領域として表示します。

- 「本文を編集」で文章や参照項目を編集し、「入力データで確認」で現在の入力値を反映した結果を確認します。繰り返しは行数分に展開し、条件に合う内容を表示します。確認画面では本文を編集できません。「本文を編集」に戻ると元の選択位置を復元します。
- 「レイアウト」から用紙・向き・余白を設定できます。余白は標準（上下左右25.4 mm）、狭い（12.7 mm）、広い（上下25.4 mm・左右50.8 mm）を選ぶか、各辺の数値を指定します。ページ設定は文書全体に適用され、元に戻す・やり直すに対応します。
- 初期の表示倍率は100%です。画面下部の表示倍率で「幅に合わせる」を選ぶと、画面サイズの変更に追従して紙面が収まります。100%などの数値は実際の表示倍率で、紙面が入りきらない場合は横にスクロールできます。

確認画面はブラウザーによる近似表示です。自動改ページ・文字の折り返しは「Wordを出力」で保存したWordファイルでも確認してください。

## 項目定義と出力仕様を取り出す

画面下の「項目定義（Definition）」から、現在の項目定義JSONを表示・コピー・保存できる。「出力定義の仕様」は配置・書式を含む公開JSON仕様を表示し、Markdownで保存できる。両方をLLMへ渡してRender Definitionを生成させ、「保存・読込 → JSONを貼り付けて読み込む」から取り込む。仕様は通常版・portable版に内蔵しており、表示に外部接続を使わない。コピーAPIが使えない環境では「全選択」からCtrl+Cでコピーする。

## 入力者

1. 「入力・書類作成」を開く。URL末尾に`#editor`がなければこの画面から始まる。「編集者画面へ」で編集画面に戻れる。
2. 「保存・読込」でDefinitionを読み込み、対応するRender Definitionを読み込む。管理者が渡した全体ファイルから開始してもよい。
3. 項目を入力する。表は許可された範囲で行を追加・削除・複製・並び替えできる。
4. 添付や画像はファイル選択で入力する。内容はDocument Dataに含まれる。
5. 「入力を検証」で型・必須・範囲・キー重複等を確認する。
6. 「保存・読込」からDocument Dataを保存し、メール等で共有する。gzipを選ぶと`.json.gz`になる。
7. 定義者が選択した形式を確認して「出力」。PDFでは印刷画面で「PDFに保存」を選ぶ。

入力は値を確定した時点（通常は入力欄からフォーカスを外したとき）で保存する。ブラウザ内の自動保存に加え、持ち出し・提出前にJSONを保存する。

## 履歴・差分・マージ

1. 作成者名を設定する。
2. 「履歴・派生」で変更内容を入力し、スナップショットを記録する。
3. 提出版から「室長修正版」等の名前で派生する。派生するとその版へ切り替わる。
4. 切替時に未記録の編集があれば自動記録してから切り替える。
5. 「差分表示」で任意の2状態、または状態と編集中の内容を比較する。行はIDで比較し、並び順は別に表示する。
6. 現在の版へ統合したい修正版を選び、「現在の版へマージ」を押す。
7. 競合があれば現在の版・修正版・親状態・削除を選ぶ。両方の内容を残す場合は値をJSONで編集して採用する。
8. マージ後に制約を検証する。重複・行数・型・順序などの問題が残る場合は確定できない。
9. 必要なら統合結果のJSONで行の追加・削除・復元・移動や値の修正を行う。新しい行には新しい`_id`を付ける。
10. マージを確定すると2つの親状態を持つ履歴が残る。

他の人の修正版は「全体」Workspaceで受け渡し、履歴画面の「修正版を取込」を使う。通常の「保存・読込」で全体を読み込むと置換になる。共通の履歴を残したまま派生し、独立した新規書類に作り直さないこと。

コメントは特定の履歴状態に付ける。履歴の「復元」は現在の版へ過去状態を復元し、新しいスナップショットとして記録する。Undo/Redoは現在のブラウザセッション内で最大40操作。自動バックアップは直近の記録・読込・マージ前の1状態。

## 和暦の年だけを入力する欄

1. 要件定義で項目を追加し、データ型を「Object」にします。
2. 「入力・表示」を開き、「和暦年の設定例を使う」を押します（子項目がないObjectで利用可能）。
3. 元号と年数の入力欄が横並びになります。子項目を選ぶと、元号一覧、年数の最小値、後ろに表示する「年」、数値1の表示名「元」を変更できます。

年数に「1」または「元」を入力すると「元」と表示し、数値1で保存します。0はエラー、未入力は空欄のままです。通常の年数8なら「令和8年」、元年なら「令和元年」と出力します。西暦変換や各元号の最終年の検証はありません。

同じ「入力・表示」の設定は通貨や単位付きの入力にも使えます。表示用の文字は保存値や数値条件の判定には含まれません。

## 更新後にWord編集でエラーが出る場合

HTMLとvendorフォルダーは同じ配布版を組み合わせてください。`docbench-runtime.js`で`Right-hand side of 'instanceof' is not an object`が出る場合、古い`vendor/tiptap.min.js`に新しいHTMLが必要とする選択APIがない可能性があります。現在の配布版の`vendor/tiptap.min.js`へ差し替え、ページを再読み込みしてください。HTTP/SharePoint経由ではキャッシュに古いファイルが残る場合があるため、差替え後も続く場合はキャッシュを無視して再読み込みします。JSONデータはそのまま利用できます。

Word編集の開始時に必要なAPIを確認し、不足があれば編集領域に対象ファイルと更新方法を表示します。HTMLだけの差替えでは外部ライブラリは更新されません。

## Wordで文章を書き、項目や制御範囲を挿入する

Wordの紙面をクリックすると、その位置の本文へ入力できます。空の書類は文章の追加操作をせず書き始められます。Enterで段落、Shift＋Enterで段落内の改行です。見出し・文字書式・箇条書き・番号付きリスト・文字揃え・行間・段落前後の余白・表・改ページを使えます。「本文を書く」で本文へ戻れます。既存の配置済み項目やデータ表の前後にも文章を書き足せます。

本文は一つの編集領域です。配置済みの文章・表・項目の境界をまたいで選択、コピー・切り取り、削除、Undo／Redoを使えます。Ctrl＋Home／Endで文書の先頭／末尾、Shiftを加えるとその位置まで選択、Ctrl＋Aで文書全体を選択します。隣接する文章要素の先頭でBackspace、末尾でDeleteを押すと前後の段落をつなぎます。既存の項目ブロックやデータ表は入力フォームへの参照を維持し、本文編集によって入力値を書き換えません。

見出しはWordの見出しスタイル・アウトライン階層として出力します。引用段落の字下げと左罫線、ヘッダーの右揃えはプレビューとWord出力へ反映します。現在のプレビューに実際のページ数の計算はなく、ページ番号の位置には「［ページ番号］」を表示します。出力したWordには実際のPAGEフィールドが入ります。

文字を選択して文字サイズの入力欄へ移動しても、選択範囲を色付きで保持します。数値の入力・上下キー・スピンボタンで連続して変更でき、Enterで本文へ戻ります。箇条書きの記号・番号にも指定したサイズと文字色を反映し、Word出力でも保持します。本文を選択して「文字色」を変更すると、その項目の記号・番号も同じ色になります。「書式解除」で指定を解除できます。入れ子のリストでは、編集中の項目だけを変更します。

「段落の設定」で左右のインデントと最初の行を指定します。単位はpt／文字で、最初の行を負数にするとぶら下げになります。行間は倍率・固定値・最小値から選び、固定値と最小値はptで指定します。段落を分割しない、次の段落と分離しない、段落前で改ページ、先頭・末尾1行を分離しない設定もWord出力へ保存されます。紙面上の自動ページ分割は未実装です。

「タブ位置」で本文領域の左端からの位置（pt）、左・中央・右・小数点揃え、点線・破線・下線のリーダーを指定します。同じ位置の「設定」は置き換えになります。未指定部分の既定タブは36pt間隔です。本文のTabでタブを挿入します。表内は従来どおりTabでセル移動、リスト内はリスト操作を優先します。ルーラーは「スタイル・番号」から表示を切り替え、左・右・最初の行のマーカーをドラッグ、または矢印キー（Shift併用で10pt）で動かします。

「スタイルの管理」では段落・文字・表スタイルを作成・複製・変更できます。空欄や「継承」は基準のスタイルに従います。本文に保存するのはスタイルへの参照なので、スタイルを変更すると適用済みの箇所も一括で変わります。段落は上部のスタイル選択、文字・表は「スタイル・番号」で適用します。個別に付けた文字書式はスタイルより優先します。「直接書式を解除」はスタイルを保ちながら個別指定を外します。表スタイル適用時には、セルの直接指定を解除するか選べます。使用中・継承元・次段落に指定されたスタイルは削除できません。スタイル定義の変更は上部バーのUndo／Redoで戻せます。

段落スタイルの「次の段落」を指定すると、段落の末尾でEnterを押したときに切り替わります。段落の途中の分割やリストのEnterは従来の操作です。見出しスタイルは見出し1〜6に対応し、カスタムスタイルにも見出し階層を指定できます。

「階層番号の設定」で1〜9階層の番号書式・開始番号・上位階層の後で再開する条件・本文の開始位置・ぶら下げ幅を設定します。%1、%2はそれぞれ第1・第2階層の番号で、`%1.%2.`や`(%2)`などを指定できます。数字、全角数字、英字、ローマ数字、アイウエオ、記号を選べます。「連動する見出し」を指定して定義を保存すると、その見出しに自動で番号が付きます。個別に適用するときは「新しい連番」「前の連番から継続」「指定番号から再開」を選びます。番号はネイティブのWord番号として出力し、本文の文字列には焼き込みません。

「差し込み」では要件の入力値や項目名を挿入できます。文章は本文に直接入力し、見出しは段落スタイルで設定します。表は「表」タブで挿入し、明細を増やす場合は「この行をくり返す」を使います。

- **要件の入力値を差し込む**：「要件で定義した項目」を押し、選択画面から項目を選んで「カーソル位置に差し込む」を押します。選択画面には検索欄と折りたためる階層があります。項目名・親項目名・キーで検索でき、同名の項目も親項目付きで区別できます。くり返しの中では、そのデータの子項目を先に表示します。「入力・書類作成」で記入された値が、この位置へ入ります。親子の項目は「申請者 › 氏名」のように表示します。現在の入力値の例を欄の下に表示し、「この項目の要件を開く」で元の定義へ移動できます。「項目名（見出し用）」を選ぶと、値の代わりに定義した表示名を差し込みます。
- **件数分くり返す**：配列・表を選び、そのデータ1件につき、枠の内側の文章・表を1回出力します。例えば経費が3件あれば、1件分の品名・金額の段落を3回出力します。枠に表を入れた場合は、その表全体をくり返します。内側では「現在の行」の子項目を差し込めます。単純な文字列・数値の配列なら「現在の値」を選べます。0件なら内側の内容をすべて省きます。
- **条件で表示を切り替える**：判定に使う項目と値、または「条件を設計」で作った条件を選びます。例えば進捗が「完了」のときだけ、完了日を含む段落を表示できます。書類全体の入力値で判定し、一致しなければ枠の内側の文章・表をすべて省きます。

表の明細行を増やす場合は、対象のセルへカーソルを置いて「表」タブの「この行をくり返す」を押します。開始行・終了行と、件数の元になる配列・表を指定します。例えば1行目が見出し、2〜3行目が明細、4行目が合計なら、開始行2・終了行3を指定すると、明細2行を1件分として出力し、見出しと合計は1回だけ残ります。Shift＋クリックで複数行のセルを選んでから開くこともできます。縦結合の途中では区切れないので、結合セル全体を1件分に含めてください。

設定した明細の先頭セルに、元になる項目と「何行を1件分にするか」を表示します。明細セルへカーソルを置き、「差込み・挿入」からそのデータの子項目を差し込みます。罫線・文字書式・セル結合は各件へ引き継ぎます。0件なら明細だけを省き、固定行が1行も残らない場合は表全体を省きます。「明細行のくり返しを変更」から対象・項目を変更でき、「くり返しを解除して行を残す」で通常の表へ戻せます。変更・解除はUndo／Redoと保存・再読込に対応します。解除後、明細の子項目を参照した差込みが残る場合は、参照も通常の項目へ変更してください。

旧画面の「範囲」は、これらの枠で囲む、ひとまとまりの文章・表のことです。文章を選択してから設定すると、選択を含む段落・表が対象になります。未選択なら、カーソル位置に文章を書き込む枠を追加します。文字の一部分だけを対象にする機能ではありません。枠の内側に文章・見出し・表や別のくり返し・表示条件を置けます。入れ子の配列は親のくり返しの内側で選びます。

枠の上端の見出しをクリックすると設定を変更できます。下端には「ここまでを1件分としてくり返す」または「ここまでを条件で表示」と表示します。「続きを外に書く」を押すと、枠の後に通常の本文の段落を追加します。Ctrl＋Enterでも同じ操作ができ、枠の外でのCtrl＋Enterは改ページです。「設定を解除して内容を残す」は文章を保持し、「内容ごと削除」は枠の内側をまとめて削除します。変更はUndo／Redoで戻せます。

編集時だけ差込みの印や枠を表示します。入力データでの確認とWord出力では、印を入力値へ置き換えてくり返し・条件を適用し、編集用の見出し・枠・操作ボタンは出力しません。出力定義には本文と参照・条件を保持し、展開済みの行データは保存しません。

### 既存の型を組み合わせる

「型を定義」でObject型の「期間」を作り、「子項目を追加」で「開始」「終了」を追加します。それぞれの「データ型」で登録済みの「和暦年」などを選べます。ArrayのObject要素やTableの列でも同様に使えます。

参照元の型を変更すると、期間の定義と書類での使用箇所へ反映します。「参照元の型を編集」で元の型に移動できます。開始・終了の名前、キー、必須設定は期間側で編集でき、参照元の内部構造は元の型で編集します。「参照を解除」すると、その子項目を独立して編集できます。自分自身や循環する型は選択候補に出ません。型定義の保存・読込では依存先も保持されます。

繰り返し入力に登録型を使う場合は、「入力形式」で「リスト型」を選び、その下に現れる「各行の型」から登録型を選びます。例えば「和暦」を選ぶと、行を追加するたびに和暦の入力欄が作られます。「和暦」の規則・表示設定・構造の変更は、入力済みの各要素と配列型の使用箇所にも反映されます。

「短い文字」の登録型なら文字入力欄、「選択肢から1つ」の登録型なら選択欄になります。「複合型」の登録型では子項目が並びます。「選んだ型を開く」で参照元の入力規則を変更できます。以前に保存した配列は、入力値を保持して読み込めます。

### 1つの明細一覧から種類別のWord報告書を作る

1. 「型を定義」で「複合型」を選び、物品（品名・個数・値段）と旅費（目的地・交通手段・金額）を別々に作ります。
2. 「型を追加」で「支出明細の種類」を作ります。「入力形式」で「選択型」を選び、物品と旅費を「選べる型」に追加して「型定義に反映」を押します。
3. 「要件を定義」で明細の「入力形式」を「リスト型」にし、直下の「各行の型」で「支出明細の種類」を選びます。必要に応じて「行数・行の操作」で行名を「明細」にし、「要件に反映」を押します。
4. 入力画面で行を追加し、物品か旅費を選びます。選んだ型の入力欄が表示されます。
5. Wordで、各報告書の「件数分くり返す」または「表の明細行をくり返す」から「明細 › 支出明細の種類 › 物品」「明細 › 支出明細の種類 › 旅費」を指定します。対象が0件のときは繰り返す部分を省きます。

以前の版で配列に直接設定した候補は「既存の行別設定」と表示されます。保存済みの明細やWordの差し込みはそのまま使えます。

### 型の順番とペイン幅

型一覧は同じフォルダ内でドラッグして並べ替えられます。型を選んで「↑ 上へ」「↓ 下へ」を使うか、一覧上でAlt＋上下キーでも移動できます。順番は書類や型定義と一緒に保存され、Undo・Redoでも戻せます。

Wordの出力設計を除く01〜05の各画面では、ペインの縦の境界線を左右にドラッグして横幅を変えられます。幅は画面ごとに記憶されます。境界線にフォーカスして左右キーで調整、Shift＋左右キーで大きく調整できます。ダブルクリックまたはHomeキーでその画面の初期幅へ戻します。幅はこのブラウザの設定として保存され、書類のデータや履歴には影響しません。

「要件を定義」の入力項目一覧は、子項目を閉じた状態で表示します。Object・Array・Tableなどの左にある三角ボタンで開閉できます。開閉状態は編集や画面切替の間は維持し、再読込すると閉じた状態に戻ります。子項目を追加した場合は、追加先を開いて新しい項目を表示します。


### 型の整理と検索

「型を定義」で型を選び、「型の説明・管理」でフォルダとタグを設定します。フォルダは `会計 / 支出` のように階層を指定し、タグは `明細、申請` のように複数指定できます。型一覧と、入力形式・各行の型・選択型の候補にある「型を検索」は、どちらもフォルダのツリーを開閉できます。検索やタグの絞り込み中は該当する型までの枝が自動で開き、解除すると元の開閉状態に戻ります。検索語を空白で区切ると、各語が型名・キー・フォルダ・タグ・説明・子項目名のいずれかに一致する型が見つかります。

型一覧の下の境界はドラッグか上下キーで調整できます。通常の一覧では名前と型の種類を1行に表示し、検索・タグ絞り込み中は一致情報を補足します。「型構造」では親項目の左にある三角ボタンで、その子項目だけを開閉できます。最初は型の直下だけが開き、下の階層は閉じています。

### 整数の表示

「入力・表示」の「整数の形式」で、3桁区切り（`1234 → 1,234`）か「固定桁数（ゼロ埋め）」を選べます。固定桁数で「桁数」を4にすると、`12` は `0012` と表示されます。0以上の整数を入力でき、指定桁数を超える値は入力エラーになります。保存と条件判定には元の数値を使います。
